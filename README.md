# HOOKD METHOD Website

React + Vite + Tailwind landing page.

## Local setup

```bash
npm install
npm run dev
```

Open the local URL that Vite prints in the terminal.

## Build

```bash
npm run build
```

## Deploy

Recommended: GitHub + Vercel.

## Contact form note

The current contact popup uses `mailto:`. It works only when the visitor has a mail client configured. For production, replace it with Resend, Formspree, or a Vercel Serverless Function.
